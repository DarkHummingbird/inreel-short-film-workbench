# 美术失败处理

| 场景 | 输出或处理 |
| --- | --- |
| 关键帧模式缺镜头 | 输入 Schema 拦截，补齐 shot 后再发起调用。 |
| 实际入画角色资料缺失 | 应用校验角色引用；如模型识别到仍缺描述，返回 needs_input 并定位角色。 |
| 参考图有 ID 但无法读取 | 可按角色描述产出草案并标记 manual_review；模型适配器只发送实际可用文件。 |
| 角色映射颠倒或引用其他项目素材 | 应用拒收，保留原参考图和关键帧；编导修正后再生成。 |

通用的解析、结构校验、重复提交与重生成规则见 [开发规格](../../开发规格.md)。
