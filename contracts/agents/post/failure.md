# 后期失败处理

| 场景 | 输出或处理 |
| --- | --- |
| 语言准备阶段缺音频或检测到错位 | ok 且列出 missing_line_ids 或 timing_issues；编导补音频、调整或替换后再确认。 |
| 合成缺少“确认节点 5：语言素材”的确认引用、音乐或必要素材，或语种／画面版本不匹配 | 应用在调用前拒绝；模型发现有未处理的对白或时序问题时返回 needs_input。历史交付保留。 |
| 泰语配音失败或太长 | 接受上传备用或重新配音；应用保留原素材，指明镜头和对白。 |
| 合成任务失败或成片不可播 | 合成服务记录错误，保留旧验收版；修复后重新合成并提交对应语种。 |

通用的解析、结构校验、重复提交与重生成规则见 [开发规格](../../开发规格.md)。
