# 导演分析：带伞

## 项目判断

- 类型：8 分钟写实动画短片中的 30 秒生活剧情场景
- 输入完整度：部分完整；人物关系与事件明确，前后场状态未知
- 核心体验：观众先从拖延动作读出不舍，再在递伞时看见双方唯一允许发生的靠近

## 明确事实、推断与建议

- 明确事实：雨夜；母亲修旧伞；成年女儿准备离家；女儿未拿门边行李；母亲问是否带伞。
- 合理推断：女儿不碰行李是在等待一个延长告别的理由。
- 导演建议：不用煽情音乐，以雨声、伞骨和鸣笛控制节奏。
- 待确认：出租车鸣笛是否属于锁定事件。

## 戏剧与人物

场次不可替代的变化，是两人从各自占据厨房与玄关，变成共同握住一把伞。母亲的目标是在不说“留下”的情况下继续照顾；女儿的目标是等到一个能够让她延迟离开的信号。母亲递伞时第一次跨出桌边区域，权力从“谁先承认不舍”转为“谁先允许接触”。

## 导演核心意图

直到递伞前都保留双人空间，不切正面特写。这样观众必须从停手、视线和未移动的行李读取情绪；递伞时靠近半个机位，让空间收缩成为视觉转折，同时保留门框，避免把离别问题伪装成已经解决。

## 场面调度与表演

母亲位于左侧餐桌，女儿位于右后方门框，行李固定在女儿右侧。母亲听到出租车时只停手半拍，不抬头；女儿说完把重心从门外侧脚移回室内侧脚。递伞前母亲停半个呼吸，女儿先看伞再抬眼，接住木柄后暂不收手。

## 摄影、剪辑与声音

第一镜用双人中全景建立距离和行李证据；在母亲停止拨动伞骨的动作停点切入第二镜。第二镜轻度压缩距离，缓慢前移半步并在双手相遇时停止。雨声全程连续，鸣笛只出现一次，交接后不进音乐，让木柄轻碰和静默承担转折。

## 连续性锚点

母亲在左、女儿在右；旧伞由母亲右手向右递出，女儿用右手接；黑色行李始终停在门框右侧；暖厨房和冷玄关的光向不变。
