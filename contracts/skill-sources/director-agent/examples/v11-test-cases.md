# Director Agent v1.1 测试输入

## 双人对话导演审核

深夜办公室，两位合伙人在同一张桌旁。乙反复整理合同，甲抽走最上方一页，乙第一次抬眼。审核镜头的导演质量和 AI 生成可行性，并给出修改决策。

## 多人物复杂动作拆分

警报走廊，四人同时争抢数据盒；持盒者转身跑向正在关闭的出口，另一人追击。判断是否能单次生成，并给出拆分后的镜头结构。

## 12 秒连续长镜头

人物沿走廊前行、右转推门、进入房间发现空椅。镜头不能出现编辑切断，但允许在门框完全遮挡时进行两段生成。

## 多镜头连续性

检查三个镜头中的脸、发型、服装、蓝杯持手、动作进度、摄影机方向、景别、光线以及首尾帧衔接。

## 通用模型适配

把同一个雨夜递伞导演母版适配为“短提示、强首帧锁定的图生视频配置”和“较长结构化提示、明确首尾状态的文生视频配置”，不得改变导演意图和连续性锚点。
