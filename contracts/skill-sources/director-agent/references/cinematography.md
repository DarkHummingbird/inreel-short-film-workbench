# Cinematography decisions

## Decision order

For each shot decide: narrative function → audience information → character state → space → shot size → position → height/angle → lens intent → movement → composition → focus → light → duration → transition.

## Required shot logic

- `narrative_function`: the change, reveal, comparison, concealment, or transition served.
- `dramatic_subject`: what the audience must read, not merely who appears.
- `shot_size`: justify how much body and space the audience needs.
- `camera_position`: identify side, distance, and relation to the action axis.
- `lens_intent`: describe spatial compression/expansion, intimacy, distortion, or separation; use millimeters only when production needs them.
- `camera_movement`: specify trigger, path, speed, and stop point. Use `static` when movement has no dramatic job.
- `focus_strategy`: state subject priority and any motivated rack focus.

## Movement test

Reject movement that exists only to look cinematic. A valid move can follow a decisive action, reveal information, transfer attention, change audience distance, express destabilization, or complete a compositional transition.

## Axis and screen direction

Establish the action axis and screen direction before coverage. If crossing the axis, use a neutral shot, visible camera move, character movement, or deliberate disorientation with a stated reason.

## Light and composition

Tie light direction, contrast, color, negative space, frames within frames, foreground occlusion, and depth to information and emotion. Preserve practical feasibility and continuity across coverage.
