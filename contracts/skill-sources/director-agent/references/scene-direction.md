# Scene direction

## Scene state change

Define the scene's dramatic purpose, objective, pre-state, post-state, turning point, information release, emotional trajectory, and continuity obligations. A usable scene plan makes the state change visible.

## Directing plan

1. Draw a simple geography: entrances, exits, obstacles, practical light, action zones, and off-screen space.
2. Place characters based on tactics and power rather than symmetry.
3. Assign movement to changes in intention. Avoid decorative pacing.
4. Map performance beats to physical behavior.
5. Choose audience access: observational, aligned, subjective, withheld, or shifting.
6. Establish coverage only after the master dramatic path works in space.
7. Define the edit principle and the moment it changes.
8. Define art, light, sound, and silence as dramatic systems.

## Useful output order

Scene function → before/after state → objectives and tactics → power curve → geography → blocking beats → performance beats → camera strategy → edit strategy → visual/sound strategy → continuity anchors → risks/open questions.

## Dialogue scenes

Do not default to mechanical shot/reverse-shot. Prefer it when spatial relations are established, performance detail is central, clean power comparison matters, and each cut reflects a psychological change. Otherwise consider shared frames, withheld reactions, foreground obstruction, motivated reframing, or an unbroken spatial progression.
