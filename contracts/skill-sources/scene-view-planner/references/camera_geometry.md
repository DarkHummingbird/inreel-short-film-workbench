# 机位几何与视角推演手册（方向 → 新视角图）

本文件指导阶段 B：用户在平面图上指定方向（箭头或"反打/左/右"）后，如何几何地推出
新机位、新画面里各物体的位置，并组装出一张**与原场景严格一致**的图生图提示词。

目录：
1. 方向语义（最重要的约定）
2. 口头方向 → 新机位朝向（反打/左/右/自定义）
3. 解析用户在图上画的箭头
4. 新视角可见性推演（含反打左右互换）
5. 一致性硬约束
6. 图生图提示词组装模板 + 卫生间反打实例
7. 生成后回查与迭代
8. 阶段 C：四宫格总览与一致性自检

---

## 1. 方向语义（最重要）

**箭头尖指向 / 用户报的方向 = 想让"相机朝向"、也就是最终画面正前方看到的那一面。**
相机永远站在"目标那面墙的对面、贴着相反一侧"，朝目标方向看过去。

- 箭头指向南墙的门 → 相机站到北侧、朝南看 → 看到南墙和门（即原机位的反打）。
- 不要把"箭头方向"误解为相机移动方向；它是**视线方向**。

## 2. 口头方向 → 新机位朝向

记原机位朝向为 F0。先按"目标墙对面站位"理解，再用下表快速换算新 facing：

| 原朝向 F0 | 正面/原视角 | 反打(180°) | 左侧视角 | 右侧视角 |
|---|---|---|---|---|
| N（站南朝北） | N | S | E | W |
| E（站西朝东） | E | W | S | N |
| S（站北朝南） | S | N | W | E |
| W（站东朝西） | W | E | N | S |

规律（方位角，北朝上）：**反打=反向；左侧=F0 顺时针 90°；右侧=F0 逆时针 90°**。
这里的"左/右"以**原拍摄者面向画面时的左右手**为准，需在回复里用"你原图的左手边/右手边"
复述一遍，避免歧义。新机位点 = 场景中心沿"新 facing 的反方向"后退到贴近该侧墙/边界。

自定义角度：用户给偏航度数（相对原朝向左转/右转多少度）或斜向方位（如 NE），按同样原则
站位——站在目标方位的对角、朝目标方位看。

## 3. 解析用户在图上画的箭头

1. 读出箭头**尖端落点**与**方向向量**（相对场景中心 C，或相对原机位）。
2. 方向向量就近归到 N/NE/E/SE/S/SW/W/NW 八方位；斜向即斜角机位。
3. 新 facing = 箭头方向；新机位点 ≈ C 沿箭头反方向退到墙边（保持与原机位相近的"贴墙距离"
   和相近视高、相近焦段）。
4. 可运行 `floorplan.py --arrow x,y,DIR` 重绘一张带红箭头的"已标注平面图"，自检方向理解是否正确，
   并在回复里用一句话复述（"箭头朝南墙的门，即站北朝南的反打视角"），确认无误再生成。
5. 用户箭头含糊（指向角落、斜跨）时，先复述你的理解让其确认，不要硬猜。

## 4. 新视角可见性推演

生成前，先在平面图上"站到新机位、面朝新方向"，列清四件事：

1. **正中/远景**：新 facing 正对面是哪面墙、哪些固定物（画面尽头的主体）。
2. **新画面的左右**：以新机位朝向重新判定左右；逐一安排物体落位。
3. **进出画面**：原正面主体会转到侧面或移出；原在侧边缘、画面外的物体会进入画面。
4. **纵深顺序**：离新机位近的物体在画面下方、显大；远的在尽头、显小。

### 反打（180°）的左右互换——最容易错，务必套用

- 绕场景中心 C 旋转 180°：平面点 (x,y) → (2Cx−x, 2Cy−y)。
- **原画面左侧的物体，反打后出现在新画面右侧；原右侧物体出现在左侧；原尽头变成身后（移出），
  原身后（画面外）变成新尽头。**
- 例：原图洗手台在画面右侧、清洁用具在左侧、尽头是隔间；反打后看到身后南墙——
  门在新画面中的左右位置要按 180° 关系重排，而非沿用原图左右。

### 侧视（90°）

- 原来只在画面左/右边缘露出一点的那面墙变成正面主体；原尽头墙转到新画面的一侧。
- 沿该侧墙排列的物体（如一整排洗手台/隔间）会从"侧向纵深排列"变成"正面横向展开"或反之，
  注意它们的前后遮挡与数量保持一致。

### 长条形空间（走廊/过道/通道）：先分清"视线垂直长墙"还是"沿长轴"

平行墙（俯视"="形）长条空间有两种本质不同的视角，判错就会得到错误的"凸"字端景，生成前必须判对：

- **视线垂直于长墙**（站在两道平行墙之间、正对其中一面长墙，如正对某扇病房门）：
  被看的墙**平行于成像平面、横向平展并向画面左右延伸出画**，地面砖缝近水平、
  **不存在两面侧墙向中心门汇聚的纵深通道**；反打 180° 后仍是同一构图（换成对面墙、挂件左右互换），
  不是"沿走廊望到底"。
- **视线沿长轴**（站在走廊一端看向另一端，即长条空间的"左侧/右侧"视角）：
  两面侧墙才向灭点汇聚、形成纵深远景。

提示词须显式写明属于哪一种。垂直长墙时要主动否定"侧墙斜向汇聚、端头凹龛、凸字形盒子空间"，
并要求**构图类型与透视关系和原图同型**（原图是贴墙平视的横向平展墙，反打也应如此）。

### 围合空间（U/L 形、院落、中庭）：先判谁在新机位"前方"还是"身后"

- 围合布局反打/侧视前，逐栋楼、逐面墙判断相对新机位是"前方可见"还是"身后不可见"，
  **不要把走廊"两排夹道"的经验照搬到院落**。
- 若开口（大门/出口）正处在机位背后方向，反打后围合建筑可能**整体位于身后、不入镜**，
  画面主体是开口及其外部；此时要显式否定原主体（"原尽头主楼/雨棚/台阶/成排窗不得出现"），
  只允许身后建筑在画面边角露出极少端部。
- 通用判据：以新机位为原点、新 facing 为前方，物体方位角落在前向 ±90° 内才可能入镜，
  落在后向半球的一律不画进画面。

### 画面外信息来源

新视角必然拍到原图没显示的区域。这些内容只能来自：① 用户明确补充；② 原图边缘可合理延伸的部分
（同款墙地砖、同款门、延续的踢脚线/吊顶）。**不得凭空添加风格不符的大件物体**；信息缺失且影响
画面时先问用户。

## 5. 一致性硬约束（图生图）

- 同一空间：户型、门窗位置、固定物数量与样式、墙地砖纹样、吊顶、灯具、洁具型号完全一致。
- 同一视觉基调：色温/色调、光照方向与强度、明暗氛围、时间、天气、画风、材质、镜头视高与焦段
  （透视强弱）保持一致；样例为冷蓝、平视、约 35mm 自然透视，就沿用。
- **只改变机位位置与朝向**，不重新装修、不换风格、不增删主要物体。
- 以**原始场景图为首要参考图**；可把俯视平面图/箭头标注图作为**布局参考**，但只借几何关系，
  严禁把其黑白线稿风格带进成图。
- 成图为静态照片级画面（默认）。用户要镜头运动视频时，改用对应视频生成能力，几何推演相同。

## 6. 图生图提示词组装模板

按五段组织，缺信息的段落不要编造：

```
【空间与风格锚点】沿用参考图同一空间与视觉风格：{空间类型、墙地砖/吊顶/材质、色温光照、画风、视高与焦段}，保持完全一致，仅更换机位。
【新机位】相机位于平面图{位置描述}，视高与原图相近，镜头朝向{新facing/箭头方向}，{正面平视/轻微俯仰}，焦段与原图一致。
【画面布局】正中尽头是{正对的墙/物体}；画面左侧是{物体}，右侧是{物体}；前景靠近镜头的是{物体}。{按第4节推演逐一点名，数量与平面图一致}
【反打/侧视关系】{如适用：相对原图左右互换 / 某排物体改为横向展开 等几何关系}
【约束】同一空间、同一光照色调与材质，不新增风格不符物体，写实、无畸变、无多余文字水印。
```

### 卫生间反打填好实例（对应范例）

```
沿用参考图同一公共卫生间与冷蓝色调、白色瓷砖墙地砖、方块吊顶、嵌入式平板灯、平视约35mm自然透视、写实电影感，仅更换机位。
相机移到隔间一侧（房间北端）、朝南正对原机位背后的南墙，视高与原图一致，正面平视。
画面正中尽头是南墙：偏左一扇关闭的浅灰色平开门（带把手），墙中部偏右挂一个白色擦手纸盒；画面右侧可见一扇向内打开的门洞；地面同款灰色瓷砖、顶部同款吊顶与筒灯。
此为原视角的180°反打：原图右侧的洗手台、左侧的清洁用具与尽头隔间均已转到身后不再入镜，左右关系相对原图互换。
保持同一空间、同一冷蓝光照与材质，不新增不符物体，无透视畸变、无文字水印。
```

## 7. 生成后回查与迭代

1. 把成图与平面图新机位对照：正中是不是该看到的那面墙？门/物体所在左右是否符合第 4 节？
2. 核对数量（几个隔间/几台盆）、门的开合、材质色调是否与原图一致。
3. 不符就**改几何/布局描述**重生成（而不是笼统说"更真实"）；常见错误对照：
   - 左右反了 → 漏了反打左右互换，按 180° 公式重排。
   - 看到了不该看到的原尽头物体 → 新机位没真正转到对面，重新定站位。
   - 空间变成"凸"字端景/两侧墙向门斜向汇聚 → 长条空间被误按"沿长轴"生成；按第 4 节"长条形空间"
     改判为视线垂直长墙，强调被看墙平行画面、横向左右延伸、无侧墙汇聚，并要求与原图同型构图。
   - 反打后仍看到原尽头主楼/原主体 → 围合空间被误按"两侧夹道"处理、新机位没真正转过去；
     按第 4 节"围合空间"把身后建筑剔除、主体改为开口/大门，并显式否定原主楼与雨棚台阶。
   - 风格漂移/像另一个房间 → 强化第 5 节锚点，并确保原图作为首要参考图。
4. 交付本视角后，提示用户可继续在同一平面图上指定下一方向（左/右/任意箭头），重复本手册流程。

## 8. 阶段 C：四宫格总览与一致性自检

单个视角逐张回查（第 7 节）容易"只见树木不见森林"。当反打/左/右等视角都出齐后，
**必须把它们和原图拼到同一张 2×2 四宫格里横向比对**——这是发现机位错乱与风格漂移最有效的手段。

### 8.1 拼图（固定机位顺序，勿改）

```bash
python scripts/make_grid.py --front 原视角.png --reverse 反打.png \
       --left 左侧.png --right 右侧.png -o grid.png
```

```
 左上 原视角 Front(F0)   │  右上 反打 Reverse(180°)
 左下 左侧 Left          │  右下 右侧 Right
```

某视角没生成就省略对应参数，该格留"未生成 N/A"，不要用别的图硬凑。

### 8.2 三项检索清单（逐项打勾）

**A. 位置关系（几何自洽）——最重要**
- [ ] 相邻两格相差正好 90°：它们共用的那面墙/那排物体，应出现在两格**相邻的画面边缘**且能衔接上。
- [ ] 对角两格（原 ↔ 反打）互为 180°：左右关系互换、**不能看到同一个尽头主体**；若原视角和反打
      都正对着同一面墙/同一栋楼，说明反打没真正转身，回第 4 节重定站位。
- [ ] 左、右两格（若都是沿长条空间长轴）应互为**反向纵深**：左侧尽头在右侧应出现在身后方向。
- [ ] 长条空间：垂直长墙的格子是"横向平展墙"，沿长轴的格子才是"两侧向灭点汇聚"，不得混用。
- [ ] 围合空间：身后半球的建筑/物体不得出现在对应格子里。

**B. 风格统一（像同一个地方）**
- [ ] 四格色温/色调、明暗氛围、时间天气一致（不能一张冷蓝一张暖黄）。
- [ ] 墙地砖、吊顶、材质纹理、灯具型号、画风与写实程度一致。
- [ ] 视高与焦段（透视强弱）相近，没有某一格明显广角畸变或俯仰视点不同。

**C. 数量与样式一致**
- [ ] 门、窗、隔间、台盆、座椅、吊灯等固定物的**数量**跨视角对得上、样式相同、开合状态合理。
- [ ] 没有某一格凭空多出/缺失大件物体，或出现风格不符的新装修。

### 8.3 发现问题后的处理
1. 先定位是**哪个机位**出错（对照平面图新机位），判断属于几何错（A 类）还是风格/数量错（B/C 类）。
2. 几何错 → 回第 2/4 节重推 facing 与可见性，改提示词的"新机位/画面布局/反打关系"段重生成该视角。
3. 风格/数量错 → 强化第 5 节锚点、确保以原图为首要参考、逐一点名固定物数量后重生成。
4. **改完必须重新运行 make_grid.py 拼新版四宫格复检**，直到三项清单全部通过，再把四宫格连同
   各视角一起交付，并向用户说明四格的机位对应关系。
