# 俯视 CAD 平面图绘制手册（场景 → plan JSON → 工程图）

本文件指导如何把用户发来的一张场景透视图，抽象成 `scripts/floorplan.py` 能渲染的
结构化平面 JSON，得到一张**黑白标准俯视建筑平面图**。渲染与图块细节以本文件为准。

目录：
1. 硬性格式规范
2. 从一张透视图反推平面（分析方法）
3. plan JSON 完整字段
4. 图块类型清单与参数
5. 常见场景元素 → 图块映射
6. 完整示例
7. 自检清单

## 1. 硬性格式规范

- **风格固定**：白底、近黑线（#111）、等粗线稿、**无填充、无阴影、无颜色、无写实纹理**；
  只有用户方向箭头允许红色。不画坐标轴、网格、尺寸线（除非用户明确要尺寸标注）。
- **视角固定为正俯视（top-down / plan view）**，不是轴测、不是鸟瞰透视。
- **坐标系北朝上**：x 向右=东，y 向上=北；单位"米"，**只要求相对比例和拓扑正确，不要求真实尺寸**。
- 外墙最粗（style.wall≈3），内墙/隔断次之（inner≈2），家具图块最细（item≈1.8）。
- 图面要"干净可读"：同类物体对齐、等距；宁可少画次要杂物，也要保证墙、门、主要固定物位置准确。
- 默认让房间长边占图面主要方向；矩形房间优先用 `room.bounds`，异形才用 `room.outline`。

## 2. 从一张透视图反推平面

按以下顺序提取，拿不准的位置用相对比例估计，并在回复里标注"推断"，必要时向用户追问画面外信息。

1. **定原机位**：相机在画面之外、贴着"观看者一侧"的墙；视线方向 = 画面纵深方向（指向画面尽头）。
   - 例：画面尽头是北墙的一排隔间 → 原机位在南侧、facing="N"。
2. **定房间轮廓**：左右两侧墙线向消失点汇聚，据此判断房间是矩形还是 L 形/走廊；估出长宽比。
3. **贴墙物体归位**：把画面里沿左墙/右墙/尽头墙的固定物（门、窗、洁具、柜、隔断、家具）
   逐一落到对应墙边，估其沿墙位置与间距。
4. **识别开口**：门（注意门板和开合方向）、门洞、推拉门、窗；门在哪面墙、大致在该墙的什么位置。
5. **画面外信息（反打/侧视的关键）**：原图看不到相机背后与侧后方。**必须结合用户补充**
   （如"对面是墙还有一道门"）；用户没说又必须用到时，明确询问，不要凭空编造背后布局。
6. **抽象成图块**：每个物体对应第 4 节的一个 type；复杂家具用 rect/circle/wall 组合近似。
7. 先画一版，**回读 PNG** 检查：机位朝向、门所在墙、左右排布是否与原图一致，再交付给用户。

> 透视估不准绝对尺寸很正常，重点是"谁在哪面墙、谁在谁左边/对面、门朝哪开"这些拓扑关系正确。

## 3. plan JSON 完整字段

```jsonc
{
  "title": "记录用，不画进图",
  "style": {"wall":3.0, "inner":2.0, "item":1.8, "margin":0.12, "compass":false},
  "room": { "bounds": {"xmin":0,"ymin":0,"xmax":6,"ymax":8} },   // 矩形
  // 异形房间改用："room": {"outline": [[x,y], ...]}（多边形顶点，逆时针/顺时针均可）
  "openings": [ /* 外墙上的门/窗，见下 */ ],
  "elements": [ /* 内墙、家具图块，见第 4 节 */ ],
  "camera": {"x":3,"y":0.7,"facing":"N","label":"原机位"}        // 可缺省；存在才画机位
}
```

### openings（外墙开口，渲染器会自动在对应墙线上"断开"）
| 字段 | 取值 | 说明 |
|---|---|---|
| kind | `door`/`slide`/`opening`/`window`/`double` | 平开门/推拉门/仅门洞/窗/双开门 |
| wall | `N`/`S`/`E`/`W` | 开在哪面外墙 |
| at | 数值 | 开口中心沿该墙的坐标（N/S 墙给 x，E/W 墙给 y） |
| width | 数值，默认 0.9 | 洞口宽度 |
| hinge | `start`/`end` | 门轴在洞口的哪一端（决定门板线方向） |
| open_deg、arc | 数值、布尔 | 仅当想画"半开门扇+开启弧"时使用；默认画关闭态门板直线（最干净） |

- `door`：洞口两端墙断开，中间画一条门板线（贴近多数 CAD 平面的简化门符号）。
- `window`：洞口处画三条平行细线。
- `slide`：两条错开半幅的线。`opening`：只断墙、不画门扇。

## 4. 图块类型清单（elements[].type）

| type | 作用 | 关键参数 |
|---|---|---|
| `wall` | 内墙/隔断板 | `p1:[x,y],p2:[x,y]`（推荐）；或 `x,y,length,orient` |
| `rect` | 通用矩形块（柜/台/柱/镜/门板/桌） | `x,y,w,d,orient(N/E/S/W),radius(圆角,0=直角)` |
| `circle` | 正圆（地漏/拖把池/圆桌/柱） | `x,y,r` |
| `toilet` | 俯视马桶（水箱+碗） | `x,y,orient`=水箱贴墙方向 |
| `sink` | 俯视洗手盆（圆角+龙头点） | `x,y,w,d,orient`=盆贴墙方向 |
| `stall_row` | 一整排卫生隔间（自动画隔板/门板，可选内置马桶） | `x,y,n,cell_w,depth,orient,toilet` |
| `sink_row` | 沿一面墙等距排一列洗手盆 | `wall,x,y0,n,pitch,w,d` |
| `counter` | 长台面+台面上 n 个盆 | `x,y,w,d,orient,basins` |
| `label` | 少量文字标注 | `x,y,text,size` |
| `arrow` | **红色**方向箭头（标注用户想看的方向） | `at:[x,y],dir(N/E/S/W 或 [dx,dy]),size` |
| `camera` | 机位（也可写顶层 camera） | `x,y,facing,label` |

朝向语义（避免画反）：
- `stall_row.orient` = **隔间开口朝向（人进入的方向）**。隔间贴北墙、开口朝房间（向南）→ `"S"`，
  排列方向自动取其垂直方向；`x,y` 为排列起点处的贴墙点。
- `sink_row.wall` = 盆所贴的那面墙；`x` 为贴墙方向坐标、`y0` 为沿墙第一个盆中心、`pitch` 为中心间距。
- `toilet/sink.orient` = 该物体**贴靠的墙方向**（水箱/龙头所在侧）。

## 5. 常见场景元素 → 图块映射

脚本内置了卫生间常用图块；其余家具一律用 `rect / circle / wall` 组合成**俯视外轮廓近似**，
保持统一线稿，不要追求内部细节。

| 场景物体 | 推荐画法 |
|---|---|
| 平开门 / 推拉门 / 门洞 / 窗 | openings 对应 kind |
| 室内半墙、淋浴隔断、屏风、L 形围合 | 多段 `wall` |
| 马桶 | `toilet` | 洗手盆/水槽 | `sink` 或 `sink_row` |
| 淋浴区 | `rect`(radius=0) 框 + 内部小 `circle`(地漏) |
| 浴缸/淋浴底盘 | `rect` 带小 `radius` |
| 桌/吧台/岛台 | `rect` | 圆桌 `circle` |
| 床 | `rect`（床体）+ 内部一个小 `rect`（枕头） |
| 沙发 | 大 `rect` + 靠背方向一条 `wall` 或内嵌细 `rect` |
| 柜/冰箱/洗衣机/电器/立柱/镜子 | `rect`（镜可细长） |
| 椅子/凳 | 小 `rect` | 一排座椅用多个等距小 `rect` |
| 灶台 | `rect` + 数个小 `circle`（炉头） |
| 楼梯 | 数条平行 `wall` 表示踏步 + 可选 `arrow` 表上下方向 |
| 车/设备/异形物 | 用最接近的 `rect`/`circle` 外轮廓，必要时 `label` 注明 |

## 6. 完整示例（公共卫生间）

```json
{
  "style": {"compass": true},
  "room": {"bounds": {"xmin":0,"ymin":0,"xmax":6,"ymax":8}},
  "openings": [
    {"kind":"door","wall":"S","at":3.0,"width":1.1,"hinge":"start"},
    {"kind":"door","wall":"E","at":6.3,"width":0.9,"hinge":"end"}
  ],
  "elements": [
    {"type":"stall_row","x":1.8,"y":8.0,"n":3,"cell_w":0.9,"depth":1.5,"orient":"S","toilet":true},
    {"type":"wall","p1":[0,6.4],"p2":[1.4,6.4]},
    {"type":"wall","p1":[1.4,6.4],"p2":[1.4,5.5]},
    {"type":"wall","p1":[0,5.5],"p2":[0.75,5.5]},
    {"type":"circle","x":0.33,"y":5.12,"r":0.17},
    {"type":"rect","x":0.33,"y":4.72,"w":0.34,"d":0.3},
    {"type":"rect","x":5.62,"y":5.35,"w":0.5,"d":0.85},
    {"type":"sink_row","wall":"E","x":5.55,"y0":2.1,"n":4,"pitch":0.85,"w":0.55,"d":0.62}
  ],
  "camera": {"x":3.0,"y":0.7,"facing":"N","label":"原机位"}
}
```

运行：

```bash
python scripts/floorplan.py plan.json -o floorplan.png --svg floorplan.svg
# 在已确认方向后叠加红色箭头（x,y,方向）重绘一版"已标注图"：
python scripts/floorplan.py plan.json -o marked.png --arrow 3,3.4,S
```

依赖：`matplotlib`（缺失时 `python -m pip install matplotlib`）。脚本会自动挑选系统中文字体。

## 7. 交付前自检

- [ ] 北朝上，原机位位置/朝向与原图纵深一致。
- [ ] 每扇门都在正确的墙、正确的一侧；该断的墙确实断开。
- [ ] 左右排布与原图镜像关系一致（可把原图与平面图并排核对）。
- [ ] 只有黑白线稿 + 可选红色箭头；无填充、无阴影、无多余文字。
- [ ] 用户补充的"画面外"信息已落进平面；仍未知且影响目标视角的部分已向用户问清。
- [ ] 已实际回读输出的 PNG，确认无图块重叠出界、无中文豆腐块。
