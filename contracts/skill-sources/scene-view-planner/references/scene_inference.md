# 冷启动场景反推手册（只给一张图、信息不足时先做什么）

本文件指导**阶段 A0**：当用户只发来一张场景图、没有说明这是什么地方、也没补充画面外信息时，
**先反推"这是什么场景、当前处于哪个功能分区、其余方向应该是什么区"，向用户陈述并取得确认后，
才允许进入阶段 A 画俯视 CAD 平面图。** 目的：把"画面外的合理推断"在动手前先和用户对齐，
避免平面图画错、反打/侧视凭空编造。

目录：
1. 什么时候必须走 A0（触发条件）
2. 三步反推法
3. 常见空间类型 → 功能分区与各方位预判
4. 推断陈述模板（直接套用）
5. 确认门控（铁律）
6. 咖啡店实例

---

## 1. 什么时候必须走 A0

满足任一即先做 A0，不要直接画 CAD：

- 用户只发了一张图，未说明空间类型 / 名称 / 当前所在位置；
- 用户想要反打、左、右等"画面外视角"，但没提供任何画面外布局线索；
- 画面只拍到某个**局部功能区**（一个吧台、一张床、一排工位、一条走廊端头），
  无法从画面本身确定整间屋子的轮廓与其余分区；
- 你对"这是什么场所"判断置信度不足，或存在两种以上合理解读。

反之可**跳过 A0**：用户已明确说清空间类型与画面外布局（如"这是我家客厅，背后是餐厅、
左边是入户门"），此时直接进入阶段 A，但仍要在交付平面图时复述一遍你的理解。

## 2. 三步反推法

### 第一步：识别"场所类型 + 当前所在分区"
从画面线索取证，不要凭氛围瞎猜：

- **设备/家具**：意式咖啡机+磨豆机+手冲壶→咖啡店吧台；马桶隔间+洗手台→卫生间；
  病床+呼叫器→病房；收银台+货架→零售；工位隔断+显示器→办公区。
- **标识/文字**：菜单黑板、房号、科室牌、导视、品牌招牌。
- **材质与装修**：工业风裸顶吊灯、居家木地板、医院洁净墙板+防撞扶手、酒店大理石。
- **采光与开口**：落地窗/卷帘门/玻璃隔断暗示临街、户外座、隔间或后场。
- 结论要落到"**什么场所的哪个功能分区**"（不是笼统的"室内"），例如"咖啡店的吧台制作区"，
  而非"一个房间"。

### 第二步：以原机位为中心，推断四个方向"应该是什么"
绝大多数经营/居住空间都由若干**功能分区**组成，当前画面只是其中一块。以镜头朝向为前，
按该类场所的典型动线，推断其余方位的分区（这是"经验先验"，必须标注为推断、可被用户纠正）：

- **正前方（画面尽头方向）**：当前视线继续延伸会到哪；
- **反打（身后 180°）**：顾客侧 / 另一侧 / 出口方向通常是什么；
- **左侧、右侧（90°）**：沿两面侧墙纵深通常连接什么分区；
- **更远处 / 画面外**：座位区、入口、后场、楼梯、卫生间等可能在哪。

### 第三步：区分"可见事实"与"经验推断"，组织成确认陈述
- 画面里**确实看到**的，当作事实陈述；画面外的，一律用"预计/通常/可能"措辞，标明是推断；
- 置信度低的方向单独点出来请用户定夺，不要藏在肯定句里。

| 办公室 | 开放工位区、会议室一角 | 通道、打印区、主管间 | 一侧工位纵深、一侧玻璃会议室 | 前台/入口、茶水间、经理室 |
| 住宅 | 客厅、卧室、厨房一角 | 沙发背后/餐厅/走廊 | 阳台、门洞、柜体墙 | 入户玄关、餐厅、卫生间、其他房间 |

> 这只是**先验假设**，用来生成一份"待确认的推断"，不是最终布局；用户的纠正永远优先。

## 4. 推断陈述模板（直接套用，发给用户确认）

```
我先按画面推断一下，你确认或纠正后我再画俯视平面图：
· 场所与当前分区：这是【场所类型】的【当前功能分区】（依据：画面里看到的___、___）。
· 以你镜头朝向为"前方"：
   - 正前方（画面尽头）：___；
   - 反打 / 转身 180°（你机位背后）：预计是【___分区】；
   - 左侧 90°：预计沿___方向，是【___】；
   - 右侧 90°：预计沿___方向，是【___】；
   - 画面外可能还有：【___、___】（这部分纯推断，置信度一般）。
请问以上判断对吗？哪里需要改？你确认后我就生成标准俯视 CAD 平面图，再按你指的方向出视角。
```

要点：一次说清、用项目符号、明确哪些是"看到的"哪些是"猜的"、把问题收敛到"确认或纠正"，
不要在同一轮里直接把 CAD 也画了。

## 5. 确认门控（铁律）

1. **未拿到用户"对/可以/确认"（或针对性纠正）之前，不进入阶段 A、不渲染平面图。**
2. 用户纠正了某处，就以纠正为准更新推断；改动较大时再复述一遍新版理解，仍需确认。
3. 用户若说"你看着办/直接生成"，视为授权你按推断走，但要在交付平面图时把所有"推断项"
   一次性标注清楚，方便其事后修正。
4. A0 的推断结论要沉淀进阶段 A 的 plan JSON（尤其画面外分区），保证后面反打/侧视有据可依，
   而不是到了阶段 B 又重新凭空想象。

## 6. 咖啡店实例（对应 A0 示例图）

画面：左侧意式咖啡机 + 银色锥斗磨豆机、墙面三块手写 COFFEE MENU 黑板、不锈钢水槽操作台、
冰箱；右侧长原木吧台、黄色磨豆机与手冲壶、一排墨绿工业风吊灯、整面落地窗（窗外有遮阳伞＝户外座）、
吧台前黑色高脚凳；暖色调、墨绿+原木+不锈钢。

A0 推断陈述：

> 这是一家**咖啡店的吧台制作区**（依据：意式咖啡机、磨豆机、手冲器具、COFFEE MENU 黑板、长吧台）。
> 以你镜头朝向为前方：
> - 正前方：沿吧台/落地窗继续延伸的吧台制作动线；
> - 反打（你身后 180°）：预计是**顾客侧**——吧台外一排高脚凳、点单/收银与取餐区，再往后是堂食座位区；
> - 左侧：沿黑板咖啡机墙纵深，预计是出品台/甜品柜或通往后场的通道；
> - 右侧：沿落地窗与长吧台纵深，预计通向**堂食座位区 / 店门入口**；
> - 画面外可能还有：堂食桌椅区、入口门头、户外座（窗外遮阳伞提示）、后场仓储（纯推断）。
>
> 这些对吗？确认后我再画俯视 CAD 平面图。
