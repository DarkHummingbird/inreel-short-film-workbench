# Changelog

All notable changes to RealShot Director will be documented in this file.

## [0.1.0] - 2026-08-09

### Added
- Pure frontend single-file application.
- Natural-language-first input workflow.
- Local rule-based inference engine.
- Character, location, time, weather and camera-style inference.
- DV / CCD / VHS / smartphone camera language.
- Character consistency prompt block.
- Realism Engine with controlled camera imperfections.
- Anti-AI behavior rules.
- Timeline generation for 5 / 10 / 15 / 30 second clips.
- Optional model, ratio and realism settings.
- One-click prompt copy.
- Netlify static deployment configuration.
- RealShot Director `SKILL.md`.
- Example prompts and project documentation.
