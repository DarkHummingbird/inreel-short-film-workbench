# Natural Language Examples

下面这些输入都应该可以直接交给 RealShot，而不需要用户先填写专业表单。

## DV / 家庭录像

```text
一个广东女生早上出门买早餐，像小时候家里DV拍的那种，老城区，阳光很好，很生活化，不要AI感。
```

```text
春节农村老家，家里人拿老摄像机拍一个年轻男生帮奶奶贴春联，真实家庭录像感。
```

## CCD

```text
一个大学女生下雨天去便利店买东西，十几年前CCD录像的感觉，朋友随手跟拍，不要像广告。
```

## 手机随拍

```text
朋友拿手机随手拍一个男生半夜下楼吃宵夜，不要电影感，就是普通生活记录。
```

## 校园

```text
大学女生放学以后一个人走出教学楼，在校门口买烤肠，像2009年同学随手拍的小视频。
```

## 更抽象的输入

```text
想要一种暑假快结束了的感觉，两个朋友都知道快分别了，但是谁也没说出来。
```

注意：这种输入涉及复杂情绪与潜台词，当前纯规则版可能无法完整理解，这是已知限制。
