# Example 02 — Modern Smartphone Casual

## User input

一个女生下班后去便利店买冰淇淋，朋友用手机边走边拍，10秒，像真实朋友圈视频。

## Expected approach

- modern smartphone preset
- no retro artifacts
- subtle stabilization only
- ordinary fluorescent convenience-store lighting
- minor exposure shift entering the store
- subject not constantly facing the camera
